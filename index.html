The problem

Your AI agents can run commands, access credentials, exfiltrate data, and install plugins. Your security team has zero visibility.

Enterprises face a binary choice: deploy AI agents with full access and accept the risk, or restrict them so heavily they can't deliver value. Neither option works when you're responsible for compliance, data protection, and incident response.

The solution

Snapper eliminates the tradeoff. A bot-in-the-loop approval model gives agents full capability while your security team keeps full visibility, real-time threat detection, and human override authority.

Snapper sits between the agent and the outside world as a bot-in-the-middle security layer. Every tool call is evaluated against configurable rules before execution. Known-safe operations auto-approve instantly. Risky actions pause the agent and route an approval request to your Telegram or Slack bot — complete with inline [Approve] / [Deny] buttons. PII-protected requests always require human sign-off. Heuristic bad actor detection identifies multi-step attack patterns. Kill chain state machines catch data exfiltration, credential theft, and privilege escalation in real time. PII lives in an AES-256-GCM encrypted vault the agent never touches. CEF/Syslog events flow to your SIEM. The result: full agent power with enterprise-grade governance.

Bot-in-the-Loop Approvals

Not every action needs a human — but dangerous ones do. Snapper's three-tier approval model auto-approves known-safe operations, requires human sign-off for risky ones (writes, deletes, external calls), and always demands approval for PII vault requests. When approval is needed, your dedicated Telegram or Slack bot sends a rich notification with inline [Approve] / [Deny] buttons. Approve from your phone in five seconds. The agent pauses and polls until you decide — then vault tokens are decrypted with a 30-second TTL and single-read expiry. Both bots support full command suites: manage rules, test commands, control your PII vault, view pending approvals, and hit the emergency kill switch. Webhook delivery and email alerts complete the notification stack.

Auto-approve · Human-required · PII-mandatory · Telegram · Slack · Webhook · Email

Security & trust

Snapper is a security product — so we hold ourselves to the same standard we enforce on agents.

Fail-Closed by Default

Every evaluation path defaults to deny. No rules configured? Deny. Rule engine error? Deny. Network timeout? Deny. This is non-negotiable — your agents never operate without policy enforcement.

Encryption at Rest

PII vault uses AES-256-GCM with HKDF-derived keys. Vault tokens are 128-bit random with domain locking and 30-second TTL. Zero plaintext PII is stored anywhere in the system.
