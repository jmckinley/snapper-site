SDK Wrappers

Drop-in wrappers for the OpenAI, Anthropic, and Google Gemini SDKs. Import snapper.wrap() instead of the raw client. Every API call is routed through Snapper for policy evaluation before reaching the model provider. One line change, full protection.

# Before from openai import OpenAI client = OpenAI() # After — one line change from snapper import wrap client = wrap(OpenAI()) # Every tool call now evaluated by Snapper

Shell Hooks

Lightweight shell scripts that intercept CLI agent commands before execution. Installed as pre-exec hooks in your shell profile. Every command an agent tries to run hits Snapper first. Works with any agent that operates through a terminal.

# Install hook (bash/zsh) curl -s $SNAPPER_URL/hooks/install | bash # Agent runs: git push origin main → Snapper evaluates: REQUIRE_APPROVAL → Slack notification: [Approve] [Deny] → On approve: command executes

Network Proxy

Go binary that intercepts all agent network traffic at the OS level. SNI-based inspection catches every request to AI providers — even from agents that bypass SDK hooks. Monitors 55+ AI domains. Transparent to agents: no code changes, no SDK integration required. The network layer catch-all.

# Agent bypasses SDK, calls OpenAI directly curl https://api.openai.com/v1/chat/completions → Proxy intercepts: SNI match (api.openai.com) → Snapper evaluates: DENY (no SDK wrapper) → Alert: Shadow AI usage detected
