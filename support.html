Getting Started

Quick Start

Register, create an agent, install the hook, add your first rule, and test — in under 5 minutes.

  1. Create your account at app.snapperprotect.com
  2. Register an agent and save the API key returned in the response
  3. Install the Snapper hook in your IDE or agent environment
  4. Create your first rule (COMMAND_ALLOW for safe read commands)
  5. Test with the evaluate endpoint or Telegram/Slack bot commands

Core Features

Rules & Policies

14 rule types including command allow/deny, rate limiting, PII gates, time restrictions, and human-in-the-loop approval. Rules evaluate in priority order; DENY always short-circuits.

COMMAND_ALLOW COMMAND_DENY RATE_LIMIT PII_GATE HUMAN_IN_LOOP CREDENTIAL_BLOCK DENYLIST TIME_RESTRICTION

PII Vault

AES-256-GCM encrypted storage for secrets. Agents see vault tokens ({{SNAPPER_VAULT:...}}), never real values. Two modes: protected (requires approval) and auto (resolves immediately).

{{SNAPPER_VAULT:<32-hex>}}

HKDF key derivation, brute-force lockout (5 failures / 15 min), 30-second TTL, one-read expiry, domain-locked tokens.

Approvals

Human-in-the-loop workflow via Telegram, Slack, or API. When a rule returns REQUIRE_APPROVAL, the agent pauses until a human approves or denies.

Allow Once — one-time approval for this specific request.
Allow Always — creates a persistent ALLOW rule for matching requests.

Alert routing: numeric owner_chat_id sends to Telegram, U-prefix sends to Slack DM.

Security

Trust Scoring

Adaptive per-agent trust score (0.5–2.0) that adjusts rate limits based on behavior. Only rate-limit breaches penalize trust — rule denials do not affect the score. Opt-in per agent via dashboard toggle or API.

0.5x min · 2.0x max · per-agent opt-in · Redis-backed

Threat Detection

Real-time behavioral analysis: 13 signal types, 7 kill chain patterns (data exfil, credential theft, PII harvest, encoded exfil, privilege escalation, vault extraction, LOTL), behavioral baselines with 7-day rolling window. Feed health monitoring with auto-recovery and air-gapped threat intel support. Built-in Red Team Simulator admin dashboard with 29 attack scenarios for validating detection rules and kill chain coverage.

Score ≥60 → approval required · ≥80 → auto-deny · Feed health: 15-min checks · Red Team: 29 scenarios

Plugin Integrity

Canary probes detect plugin removal/disabling (heartbeat every 5 min, alert on 3 misses). Evaluation receipts detect selective bypass (single-use UUID on every allow, verifiable by downstream proxies via X-Snapper-Receipt).

Canary: 5-min heartbeat · Receipts: 60s TTL, single-use

Emergency Controls

Instant kill switch. /block stops ALL agents immediately via Telegram, Slack, or API. Creates priority-1000 DENY rules across all rule types. /unblock resumes normal operations.

Priority 1000 · all agents · all rule types · instant

Network Enforcement

Snapper enforces at three layers: SDK hooks (voluntary), network proxy (mandatory), and code scanner (pre-deployment). Together they ensure no AI traffic escapes governance.

Network Proxy

Transparent HTTPS proxy (Go binary, <15MB) that intercepts AI API traffic at the network layer. Monitors 55+ AI provider domains. Two modes: SNI (zero-config, domain-level) and MITM (full request inspection with canary token injection). Circuit breaker, Prometheus metrics, SIEM integration, fail-open/closed, config sync from Snapper API.

55+ AI domains SNI mode MITM mode Canary tokens Prometheus Circuit breaker

Code Scanner

CI/CD scanner (Go binary, <15MB) that detects ungoverned AI before deployment. 8 detection categories across 3 scan tiers (basic/standard/full): unwrapped AI SDKs (CRITICAL), hardcoded endpoints, leaked credentials, missing dependencies, agent frameworks, MCP servers, AI infra, and unguarded prompts. Each organization picks the right tier for their maturity level. SARIF output for GitHub Security tab. Dedicated Scan Reports dashboard with findings trend charts and compliance report integration.

3 scan tiers 8 categories SARIF output GitHub Action Scan Reports UI Python/JS/Go/Java

Enterprise Features

SIEM Integration

Per-org SIEM targets with 4 transport types: Syslog (TLS), Webhook (HMAC-SHA256), Splunk HEC, and Azure Sentinel. CEF event format, secret redaction, and test connectivity.

MCP Integrity Verification

Tool manifest SHA-256 hashing with 8 suspicious-tool heuristics (credential harvester, prompt injection, encoded payload, and more). Per-org allowlists and risk scoring (0-100).

Plugin Integrity (Canary + Receipts)

Canary probes detect plugin removal/disabling (5-min heartbeat, alert after 3 misses). Evaluation receipts provide single-use proof that each tool call was evaluated, verifiable by downstream proxies.

Organization Policy

Organization-level security policies: MFA requirement, login lockout, session timeout, and audit retention. Admin-only access with audit-logged changes.

Organization Audit Log

Filtered audit trail scoped to your organization. Filter by severity, action type, date range, and text search. CSV export up to 10,000 records. Detail modal with full event context.

Meta-Admin Feature Flags

Per-org feature flag management UI. Toggle built-in flags (Slack, SSO, threat detection, browser extension), add custom flags, filter by plan. Platform admin only.

Cross-Org Audit

Platform-wide audit log for meta admins. Filter by organization, action type (26 types across 8 categories), severity, and date range. CSV export and detail modal.

Feed Health Monitoring

Redis-based health tracking for all security feeds (NVD, GitHub, ClawHub, MCP catalog). Staleness detection, auto-recovery of stale feeds, critical alerts on 3+ failures, and dashboard status card.

Performance Monitoring

Fleet health scoring (composite 0-100 per agent), evaluation latency breakdown (p50/p95/p99), 7-day activity heatmaps, denial hotspot tracking with trend analysis, and rule efficiency reports with dead/noisy classification. Auto-refreshes every 30s.

Air-Gapped Deployments

Full threat intelligence without internet. Curated CVE/advisory bundle (20 records), file import for custom intel, 4 deployment modes (cloud, private cloud, private server, air-gapped).
